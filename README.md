# ItemForge

**物品工坊**

ItemForge 是一个可视化自定义物品制作工具。

无需编写代码，只需填写物品信息、选择功能并上传图片，即可生成可安装的 Mod 物品包。

---

## 主要功能

* 自定义中文名、英文名和物品 ID
* 自动将常见图片转换为游戏可用贴图
* 自定义物品占格大小
* 一个物品可同时拥有多个标签
* 自动匹配顾客货源
* 批量保存多个物品并生成一个 DLL
* 支持食物、饮料、医疗品、工具和刀类武器
* 支持违禁品等级与窃贼赃物状态
* 支持工具拾荒加成与多个目标物品
* 支持钓鱼 / 专属产出模式
* 支持自定义加工配方
* 一键安装，更新和卸载生成的物品包(当你生成一样id的物品包时会直接覆盖之前的物品包)

---

## 使用方法

1. 启动 `ProbablyStolenItemForge.exe`
2. 选择游戏根目录
3. 点击 **“安装 / 更新公共 Runtime”**
4. 填写物品名称、ID、说明和价格
5. 上传图片并选择占格大小
6. 根据需要添加标签和扩展功能
7. 将物品保存到列表
8. 可以继续创建其他物品
9. 一键生成并安装物品包 DLL
10. 重启游戏

---

## 分享生成的 Mod

如果想把 ItemForge 生成的 Mod 分享给其他玩家，请将以下两个文件一起提供：

```text
PSItemPack_你的物品包名称.dll
ProbablyStolenItemForgeRuntime.dll
```

接收者只需将两个 DLL 放入游戏的 `Mods` 文件夹并重启游戏，如果你制作了两个不同的物品包则需要给对方发送三个文件(两个物品包+runtime)

**不需要安装 ItemForge 制作程序。**

# 人物工坊 CharacterForge

CharacterForge 是一个**可视化自定义人物制作工具**。无需编写代码，只需设置人物信息、到店周期、携带货物并上传图片，即可生成可安装的人物 Mod 包。

本工具可与物品工坊ItemForge搭配使用
https://discord.com/channels/1315752321975845004/1546405870647246918

## 主要功能

- 自定义人物 ID 和游戏内姓名
- 复用原版人物的行为与交易流程
- 自定义首次到店日期、到店间隔和出现概率
- 设置固定货物、数量范围及独立出现概率
- 支持带权重的随机货物候选池
- 支持原版物品和 ItemForge 制作的自定义物品
- 可直接读取 ItemForge 生成的物品包并批量导入货物
- 可选择替换模板原货物，或在原货物基础上追加
- 自定义人物出售与收购物品的价格
- 一个人物包可保存多个人物并生成一个 DLL
- 可以读取已生成的人物包 DLL，恢复配置和图片后继续修改
- 一键安装、更新和卸载生成的人物包

> CharacterForge 复用原版人物的基础行为和交易流程，目前不支持制作全新的对白系统，自定义图像功能还没有实现，请选择模板。
>
> 使用相同人物包 ID 再次生成时，会覆盖之前安装的同名人物包。

## 使用方法

1. 启动 `CharacterForge.exe`
2. 选择游戏根目录
3. 点击 **“安装 / 更新公共 Runtime”**
4. 填写人物 ID、游戏内姓名并选择行为模板
5. 设置人物首次到店日、间隔天数和到店概率
6. 根据需要上传人物图片
7. 添加固定货物或随机候选货物
8. 设置货物数量、概率、权重和交易价格
9. 点击 **“保存当前人物”**
10. 可以继续制作并保存其他人物
11. 填写人物包 ID、名称和作者
12. 一键生成并安装人物包 DLL
13. 重启游戏

## 分享生成的人物 Mod

将以下文件一起提供给其他玩家：

- `PSCharacterPack_你的人物包名称.dll`
- `CharacterForgeRuntime.dll`

接收者只需将两个 DLL 放入游戏的 `Mods` 文件夹并重启游戏，**不需要安装 CharacterForge 制作程序**。

如果人物使用了 ItemForge 制作的自定义物品，还需要一并提供：

- 对应的 `PSItemPack_*.dll`
- `ItemForgeRuntime.dll`

多个人物包可以共用同一个 `CharacterForgeRuntime.dll`。

## 注意事项

- 安装、更新或卸载 DLL 前，请先完全退出游戏
- 人物 ID 应使用小写英文字母、数字和下划线，并以小写字母开头
- 不同人物不要使用相同的人物 ID
- 自定义人物只引用物品 ID，不会自动安装对应的物品包
- 修改人物后需要重新保存、生成并覆盖安装人物包
- 如果人物仍携带模板原货物，请勾选 **“只带上述货物”**

# 自制 Mod：去钓鱼！

一个添加 **钓鱼、随机鱼重和鱼类加工玩法** 的物品 Mod。

## 玩法说明

携带 **钓鱼竿** 外出拾荒，即可随机获得 **小黄鱼** 或 **大黄鱼**。

将 **生锈的片肉刀** 拖到 **大黄鱼** 上，可以把它加工成鱼肉。

例如：

> 一条重 **2 kg** 的大黄鱼，按 **60% 出肉率** 加工后，会得到一份约 **1.2 kg** 的鱼肉。

---

## 安装方法

将以下两个文件放入游戏的 `Mods` 文件夹：

```text
PSItemPack_Gofishing.dll
ProbablyStolenItemForgeRuntime.dll
```

安装完成后重启游戏即可。
