# ItemForge
物品生成器，一个用于批量生成物品的小程序，A beginner-friendly, quick item generator for Probably Stolen.

主要功能：
- 支持中文名、英文名和自定义物品 ID
- 常见图片格式自动转换与缩放
- 自定义物品占格大小
- 多种物品目录与可叠加标签
- 支持食物 kcal、投喂机能量和饮料解渴
- 支持原版医疗物品功能
- 支持违禁等级与窃贼来源赃物热度
- 根据标签自动匹配货源，也可手动选择顾客
- 可保存多个物品，一次生成到同一个 DLL
- 自动安装、检索条目管理和物品包卸载
- 自动保存编辑草稿

使用方法：
完整解压压缩包，双击 ProbablyStolenItemForge.exe，确认游戏目录后填写物品信息，保存到物品列表，最后点击“生成列表为一个 DLL”，DLL文件会自动存入游戏文件夹无须手动加入。

注意：需要游戏已经安装并运行过 MelonLoader，生成或覆盖 DLL 前请完全退出游戏。
