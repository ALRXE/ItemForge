# ItemForge
物品工坊

ItemForge 是一个可视化自定义物品制作工具。
无需编写代码，只需填写物品信息、选择功能并上传图片，即可生成可安装的 Mod 物品包。

主要功能
自定义中文名、英文名和物品 ID
自动将常见图片转换为游戏可用贴图
自定义物品占格大小
一个物品可同时拥有多个标签
自动匹配顾客货源
批量保存多个物品并生成一个 DLL
支持食物、饮料、医疗品、工具和刀类武器
支持违禁品等级与窃贼赃物状态
支持工具拾荒加成与多个目标物品
支持钓鱼/专属产出模式
支持自定义加工配方
自动安装、更新和卸载生成的物品包

使用方法
启动 ProbablyStolenItemForge.exe。
选择游戏根目录。
点击“安装 / 更新公共 Runtime”。
填写物品名称、ID、说明和价格。
上传图片并选择占格大小。
根据需要添加标签和扩展功能。
将物品保存到列表。
可以继续创建其他物品。
一键生成并安装物品包 DLL。
重启游戏。

分享生成的 Mod
将以下文件一起提供给其他玩家：
PSItemPack_你的物品包名称.dll
ProbablyStolenItemForgeRuntime.dll
接收者只需将两个 DLL 放进游戏的 Mods 文件夹并重启游戏，不需要安装 ItemForge 制作程序。

以下为自制mod
去钓鱼！
一个添加钓鱼、随机鱼重和鱼类加工玩法的物品 Mod。
新增内容
- 钓鱼竿：拥有后，外出拾荒只会获得鱼类，不再获得原版拾荒材料。
- 小黄鱼：拥有随机重量，价值和 Kcal 随重量变化。
- 大黄鱼：体型更大，价值和 Kcal 同样按实际重量计算。
- 生锈的片肉刀：可以加工大黄鱼。
- 鱼肉：加工后固定生成一份，重量为原鱼重量的 60%，价值和 Kcal 根据最终重量计算。
玩法说明
携带钓鱼竿外出拾荒，即可随机获得小黄鱼或大黄鱼。将生锈的片肉刀拖到大黄鱼上，可以把它加工成鱼肉。
例如，一条重 2 kg 的大黄鱼，按 60% 出肉率加工后，会得到一份约 1.2 kg 的鱼肉。
安装方法
将以下两个文件放入游戏的 Mods 文件夹：
- PSItemPack_Gofishing.dll
- ProbablyStolenItemForgeRuntime.dll
安装后重启游戏。
